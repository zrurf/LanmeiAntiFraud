## 6 路由诊断（专家分工检验）

**对角占比** = 真实类别 i 被路由到专家 i 的比例；随机水平为 10%。

| 权重 | 对角占比均值 | 专家边际标准差（越小越均衡） |
| --- | --- | --- |
| stage3 路由阶段（联合训练前） | **0.032794** | 0.039035 |
| joint 联合训练后（主结果） | **0.052994** | 0.080213 |
| 冻结路由器联合训练 | **0.032794** | 0.039035 |

三种权重下对角占比均远低于随机 10%，**按类别分工从未出现**。根因是专家在全部 10 类数据上训练、仅 3 倍自权重，被训成略有偏好的通才，路由器没有可学的按类信号。

## 8 复现命令

```bash
# 训练（β=0.9999；batch 64/64/128/128/64；轮数 MLM 3 / 单头 5 / 专家 5 / 路由 10 / 联合 3）
python -m train all --no-resume --loss-defaults-beta 0.9999 \
  --train-mlm-pretrain-batch-size 64 --train-clf-train-batch-size 64 \
  --train-expert-train-batch-size 128 --train-router-train-batch-size 128 \
  --train-joint-train-batch-size 64
# 导出与测试集评估
python -m scripts.export_model
python -m tests.baseline.eval_testset --mode moe --fusion gated --out artifacts/results/moe_gated.json
python -m tests.baseline.tfidf --out artifacts/results/tfidf_baseline.json
python -m tests.baseline.tfidf_augmented --aug-rate 0.3
# 扰动 / 路由诊断 / 融合 / 标定
python -m tests.baseline.eval_perturbed --checkpoint artifacts/export/joint/model.pt
python -m tests.baseline.route_diagnose --checkpoint artifacts/export/joint/model.pt
python -m tests.baseline.fuse_moe_tfidf --variant clean
python -m tests.baseline.calibrate_fusion --checkpoint artifacts/export/joint/model.pt
# 均衡权重消融：重训路由（5 轮 · batch 128 · 写入 artifacts/routefix）
python -m train stage3 --loss-defaults-balance-weight 0.3 \
  --train-router-train-batch-size 128 --train-router-train-epochs 5 \
  --output-export-path artifacts/routefix
# 冻结路由器的联合训练（3 轮 · batch 64 · 写入 artifacts/routefix2）
python -m train stage4 --no-resume --no-train-compile --train-joint-freeze-router \
  --train-joint-train-batch-size 64 --output-export-path artifacts/routefix2
```

## 9 局限与待办

1. **专家未形成按类分工**（对角占比 3.3%~5.3%，低于随机 10%）；根因是专家在全部 10 类上训练。改进方向：让专家 i 主要在其负责类上训练（大幅提高 `self_weight` 或按类采样），并用 `route_diagnose` 验证。
2. 温度标定需要一个留出的校准集；MoE 单独无需任何后处理即有 ECE 0.0040。
3. 融合权重的最优值（测试集网格搜索）恰为等权。
4. `max_length=512` 截断长文本：测试集按 token 实测 **2.99%** 被截断（刷单类 17.69%），而 TF-IDF 看全文，这一比较对神经模型结构性不利。
5. `test_synthetic`（1341078 行，仅类别 4/5/6）无代码消费，合成鲁棒性评估尚未实现。
